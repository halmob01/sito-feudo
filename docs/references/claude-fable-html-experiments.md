Raccolta: 76 studi HTML autocontenuti (Canvas 2D, interfacce, tipografia, animazioni, simulazioni fisiche).
Archivio di riferimento fornito: `Claude Fable 5.2 HTML Files.webarchive` (salva la pagina indice e alcune miniature, non tutti i 76 sorgenti).

## Scopo per sito-feudo
Archivio di ispirazione tecnica per il motore riutilizzabile delle esperienze didattiche. Studiare il codice degli esperimenti e isolare pattern trasferibili, senza importare indiscriminatamente interi progetti.

## Esperimenti da esaminare per primi
- [001 — Suminagashi / marbling tray](https://miaai-lab.github.io/Claude-Fable-5.2-HTML-Files/001-suminagashi-marbling-tray.html): deformazione di polilinee, interazione puntatore, Canvas 2D, animazioni progressive.
- [002 — Aerodrome Lisbeth / split-flap](https://miaai-lab.github.io/Claude-Fable-5.2-HTML-Files/002-airship-terminal-split-flap.html): microanimazioni tipografiche e feedback di stato.
- [004 — Lighthouse keeper / night watch](https://miaai-lab.github.io/Claude-Fable-5.2-HTML-Files/004-lighthouse-keeper-night-watch.html): scena narrativa e interazioni ambientali.
- [005 — Working slide rule](https://miaai-lab.github.io/Claude-Fable-5.2-HTML-Files/005-working-slide-rule.html): manipolazione diretta di un oggetto didattico.

## Procedura di riuso
1. Aprire l'esperimento e leggere il relativo file HTML e, se disponibile, il prompt .txt.
2. Identificare algoritmi, input, rendering e stato separatamente.
3. Estrarre un modulo autonomo con API documentata e senza dipendenze dalla demo.
4. Verificare accessibilità, mobile, performance e integrazione con il motore.
5. Controllare licenza e attribuzioni prima di copiare codice: la disponibilità pubblica non equivale a una licenza di riutilizzo.

Stato: riferimento catalogato; codice degli esperimenti **non ancora importato**.
